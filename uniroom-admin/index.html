Bulk Account Creation

Register many students or faculty members at once by uploading a CSV or Excel (.xlsx) file. The system checks every row and tells you about missing or duplicate information before any account is created.

  1. Download the template One account per row. Keep the first row (column names) as it is.
    For a demo: a ready-made file with 4 accounts – 2 students (1 BSIT, 1 BSMEDTECH) and 2 faculty (1 BSIT, 1 BSMEDTECH). Their emails all go to the UniRoom Gmail inbox (uniroomsystem+name@gmail.com), so you can show the emails arriving.
    Demo file (Excel) Demo file (CSV) Demo file with mistakes (shows the error checking)
  2. Fill in the required columns first_name*, last_name*, email*, gender* (Male / Female / Prefer not to say), age*, role* (student / faculty), department* (the program code, e.g. BSIT). Students also need section* and student_id*. Optional: employee_id, contact_number.
  3. Choose how users get their password
  4. Upload the file
